# Guidelines for reporting issues

We have put together a short set of guidelines you can follow while adding an issue to our GitHub issue tracker. Following the information in this guide will help us to triage the issues quickly, reduce the feedback loop and ensure a speedy resolution.

This issue tracker is only for **Passport CLI** related issues. If you have issues specific to the Postman App or Web platform, a better place to report them would be the [Postman App Support issue tracker](https://github.com/postmanlabs/postman-app-support/issues).

If you are facing a specific account related issue and you want to include personal information such as your username or workspace names, reach out to us by submitting a ticket on our [support page](https://www.postman.com/support/).

If you want to report a security issue in any of Postman's services or products, read our [security reporting guidelines and policy](https://www.postman.com/vulnerability-reporting) for more details.

For answers to questions along the lines of "How do I... with the Passport CLI" should be in our online documentation at https://learning.postman.com/. If you are unable to find a how-to guide in our online documentation, feel free to ask your question on our [Postman Community Forum](https://community.postman.com).

Before reporting an issue, please use the search feature on the issues page to check if there are issues similar to yours. A lot of issues are duplicates, and it is hard to keep track of them or respond when the issues are solved. If you find your issue already reported, feel free to add a "thumbs up" reaction or provide a comment on the open issues thread.

When reporting a new issue in the issue tracker, check whether it helps to answer the following questions:

- Which **Passport CLI** version and Operating System version you are using. You can check the CLI version by running `passport --version`.

- Is the bug reproducible every time, or do you see it occasionally? Provide the full steps and the exact command(s) to reproduce the problem.

- Did you first encounter it recently, or has it always been there?

- Include the full command output and any error messages. Please ensure that these are formatted correctly using the code block markdown syntax.

- If the issue is related to a specific configuration or profile, attach the relevant (redacted) config snippet.

- Include any relevant log or debug details. Re-running the command with verbose/debug output enabled helps us tremendously.
